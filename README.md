para rodar o projeto deve instalar o Framework laravel no seu computador usando o composer,
se você esta usando o programa Laragon o composer já vem instalado por padrão
então é só abrir o terminal do Laragon e digitar os seguintes comandos:

1- composer global require laravel/installer


caso esteja a usar o Xampp você deve instalar o composer primeiro e depois instalar o FrameWork Laravel
